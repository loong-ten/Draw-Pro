# 画境 Pro · 专业绘画工作台

画境 Pro 将「画境 · Paint Studio」「Pixelroom · 像素工坊」「拼境 · 图片拼接工作台」和「Pixel Perfect Lab · 像素优化工作台」整合进一个浏览器应用，并加入图片像素转换和自动透明扩边。六种模式共用素材工作区，转换、编辑、拼接、优化和扩边的结果可直接继续加工。

应用使用原生 JavaScript ES 模块、Canvas 2D、Web Worker 和 IndexedDB。图片在当前浏览器中处理；应用代码不会把用户图片上传到服务器。没有前端依赖安装、外部字体或构建步骤。

## 六种工作模式

顶部导航按 **像素转换 → 绘画 → 精修 → 拼接 → 像素优化 → 透明扩边** 排列，像素转换入口位于绘画之前。

| 模式 | 主要能力 | 与工作区的连接 |
| --- | --- | --- |
| **像素转换** | 图片像素化、限色、三种采样、输出缩放、透明度、前后对比与 PNG/SVG 导出 | 读取当前素材的可见图层；保存为新素材后可直接进入绘画，也可批量新增或转换为 ZIP |
| **绘画** | 多文档标签、分层绘画、文字与形状、选区、裁剪、变换、填充、共享参考 | 每张素材拥有独立图层和操作历史，可从工作目录或文件导入 |
| **精修** | 亮度、对比度、饱和度、色相、模糊、预设、锐化、像素检查、导航器和历史 | 直接编辑当前素材的活动图层；参数先预览，应用后写回图层 |
| **拼接** | 无限场景、多图自由摆放、卡槽组装、多选、缩放旋转、翻转、对齐与自动排列 | 从统一素材区添加图片；拼接结果可送回绘画，继续分层编辑 |
| **像素优化** | 网格识别与偏移、采样、限色、透明边缘、孤点清理、滑杆/并排/结果对比、整数倍率导出 | 读取当前图片或图层；结果可成为新素材或结果图层，也可逐张批量处理 |
| **透明扩边** | 常用宽高比、画布倍数、目标尺寸、透明像素填充、自动内容居中与结果预览 | 直接应用当前素材或整个工作区，保留图层；也可导出透明 PNG |

`workbench.js` 统一协调六种模式。像素转换以原图快照和独立 Worker 生成结果；绘画和精修使用同一组 `PaintDocument`；拼接保留自己的源图片与变换场景；优化保留参数，通过 Worker 计算；透明扩边读取素材快照并对全部图层统一平移。各模块通过应用接口读取素材、提交结果和保存配置。

## 开始使用

1. 点击 **打开工作目录** 或 **导入图片**，也可以直接拖入图片。左侧素材列表和顶部文档标签选择当前图片。
2. 需要将图片转为像素风格时，先打开 **像素转换**，调节参数并对比结果，点击 **保存新素材并进入绘画** 继续编辑。
3. 在 **绘画** 中编辑素材，每张图片分别保留图层、视图和当前会话的撤销记录。
4. 在 **精修** 中调节活动图层。滑杆只生成临时预览，点击 **应用调整** 才写回；重置、切换目标或离开相关面板/模式会取消未应用的预览。
5. 在 **拼接** 中添加工作区素材，自动排列、自由摆放，或用右侧 **卡槽组装** 连接主体与配件。结果可以返回绘画工作区继续分层编辑。
6. 在 **像素优化** 中对比原图与结果，确认参数后点击 **应用优化** 更新当前素材，或用 **工作区批量应用** 更新工作区中的各张素材；也可以创建新素材或导出 PNG。
7. 在 **透明扩边** 中选择宽高比、画布倍数或目标尺寸，预览自动居中的结果，再应用到当前素材或工作区。也可通过 **图像 → 透明扩边 / 自动居中** 打开。
8. 使用 **导出图片** 保存最终图像；使用 **保存工作区项目** 保留完整编辑数据。

## 图片像素转换

参考「PixelTool · 本地像素画生成器」的处理流程，使用当前素材的可见图层合成图建立原图快照。可以在面板导入图片或文件夹，也可从左侧切换素材；参数变化始终重新处理输入快照，不叠加处理上一次转换结果。

| 参数 | 范围与行为 |
| --- | --- |
| 像素块大小 | 2–32 px，默认 8 px |
| 最大颜色数 | 2–256 色，默认 128；界面显示结果的实际 RGB 颜色数 |
| 输出缩放 | 10–100%，默认 100%；先缩放原图，再采样像素块 |
| 采样方法 | 主色调、平均值、中位数 |
| 网格对齐 | 默认开启；输出宽高向上补齐为像素块大小的整数倍，最后一格延展至完整块。关闭时保留缩放后的尺寸，末格可小于完整块 |
| 保留透明背景 | 默认开启；完全透明像素不参与 RGB 统计，半透明区域参与透明度加权。关闭时先合成到白底 |

- **预览与输出一致**：支持前后对比、仅结果和原图视图，以及缩放、平移和网格辅助。原图按输出比例显示以便对照；网格标记不会导出。右侧和底部的源像素都参与采样，PNG 与 SVG 使用相同的像素块几何。
- **保存为新素材**：点击 **保存为工作区新素材** 增加一张结果，保持当前原素材选中；点击 **保存新素材并进入绘画** 则选中新素材并打开绘画。两种操作均不覆盖原图，结果以独立单图层文档继续编辑。
- **PNG / SVG 导出**：PNG 保留转换结果的透明度；SVG 以矩形表示像素块，保留透明与半透明，并合并同一行连续的相同色块。
- **工作区批量转换**：固定开始时的素材列表、参数和导出格式，每张图片独立计算输出尺寸。可批量保存新素材，或把转换结果打包为 PNG/SVG ZIP；新增结果不会再进入本轮队列。停止或离开面板会取消后续处理，已保存的新素材保留；已修改或关闭的来源会跳过。
- **工程与草稿**：转换参数、预览方式、格式和网格显示状态随 `.paintspace` 与本机草稿保存。转换预览可按素材和参数重新生成；正式保留结果时使用保存新素材或下载。
- **处理限制**：缩放后的单张输入最多 16,777,216 像素；SVG 最多 100,000 个合并后矩形，超限时需增大像素块或改用 PNG。工作区最多 100 张素材，批量新增前会检查剩余位置；导出 ZIP 不占用新增素材位置。

## 拼接中的卡槽组装

参考素材拼装 HTML 的「主体卡槽 + 配件对接点」机制，卡槽可用于任意图片素材，不需要预先分类。

1. 选中主体图层，在右侧 **卡槽组装 → 编辑卡槽** 打开原图预览。点击素材添加卡槽，拖动调整位置，也可输入原图像素 X/Y；每层最多 6 槽，可命名、删除和重置位置。
2. 配件默认以素材中心作为对接点。需要其他安装位置时，选中配件并点击 **对接点**，在原图上点击或输入坐标。
3. 开启 **卡槽吸附** 后，将配件拖近主体空槽（22 个屏幕像素内），画布会高亮候选并提示松开对接。也可从 **配件对接到** 下拉框选择「主体 / 卡槽」，点击 **对接到卡槽**。
4. 每槽最多连接一个配件。拖动只吸附空槽；选择已占用的卡槽后，按钮变为 **替换槽内配件**。替换只解除原配件的连接，原配件仍留在画布原位置。已锁定的配件需先解锁才能替换。

对接约束保持两个锚点的世界坐标重合。主体移动、缩放、旋转或翻转后，配件对接点跟随卡槽位置；配件本身的尺寸、角度、翻转独立控制。一个图层也可同时拥有卡槽并连接到其他主体，系统拒绝循环连接。锁定限制直接编辑，已锁定的配件仍按连接关系跟随主体；隐藏图层不作为拖动吸附目标。

- **自由移动**：拖动已连接配件会先解除原连接；松开时可连接新的空槽。按住 `Alt` 暂停卡槽及边缘/参考线吸附。仅点击配件不会解除连接。方向键微调或更改 X/Y 也会解除该配件的对接。
- **整组处理**：点击 **选中整个组件**，可一起移动或复制。多选主体和配件不会重复平移；复制整组会重新关联复制后的主体。只复制配件时，新副本独立放置。
- **保留位置**：解除对接、替换配件、删除主体或删除卡槽后，相关配件保留当前世界位置。对齐与自动排列会解除所选配件的对接；排列同时将旋转归零。
- **编辑与撤销**：锚点编辑先保存在弹窗草稿中，点击 **保存锚点** 才应用；取消与 Escape 不更改场景。连接、替换、解除、编辑、复制和删除都可撤销/重做；取消画布拖动会恢复整个组件。
- **保存与输出**：卡槽名称、原图相对坐标、对接点和连接关系随完整 `.paintspace` 与本机草稿保存；旧工程没有这些字段时使用空卡槽和中心对接点。图片导出及送回绘画均只输出素材像素，卡槽标记不会写入图片。送回绘画保留分层像素，原拼接场景继续保留可编辑连接。

## 自动透明扩边

透明扩边参考 PNG 填充工具的目标画布流程，自动计算中心，无需在图片上手选中心点。

- **自动内容居中**：扫描可见图层合成图中全部 `alpha > 0` 的像素，以包围盒中点作为内容中心，半透明边缘也计入。完全透明的素材使用画布中心。
- **保持原像素**：扩大画布并进行整数像素平移，原素材不缩放、不裁切；原画布中的既有透明边也完整保留。已有透明边不对称时，自动居中可能需要更大的输出画布。
- **保留图层**：应用时所有图层使用相同偏移，包括隐藏或锁定图层；图层名称、可见性、不透明度和混合模式保持。扩边不会将素材合并成单层。
- **独立预览**：调整参数始终根据读取时的素材快照重新计算，不会随着选择多个比例反复累加扩边。预览中的边框与中心辅助标记不写入导出的 PNG。
- **比例与尺寸**：提供 `1:1、4:3、3:2、16:9、2:1、3:1、4:1、1:2、3:4、9:16` 及自定义比例，另有 `1.25× / 1.5× / 2× / 3× / 4×` 画布倍率和指定像素尺寸。统一宽高比允许每张图片输出不同尺寸；批量勾选“全部统一为相同像素尺寸”会为有效素材求共同画布。指定目标宽高始终严格执行，目标尺寸不足的图片会提示原因，不缩小或裁切像素。
- **整数像素居中**：奇偶尺寸不匹配时，几何中心允许最多半个像素的偏差，以保持完整像素。按同一宽高比重复计算不会因这一舍入误差不断扩大画布。
- **工作区批处理**：先预览逐张尺寸，再应用；各图使用自身内容中心，分别记录历史，可在对应素材中撤销或重做。中途停止后，同一参数下续跑会保留本批次快照并跳过已完成项，避免倍率累计。扩边参数随工作区项目和本机草稿保存。全透明素材若设置额外留白，会以原画布作为留白主体。

共享参考仍使用工作区既定坐标或相对比例；不会因单张素材扩边而整体平移其他素材的参考。透明扩边依据透明度识别范围，不会自动将图片中的白色或其他不透明背景抠除。

## 应用像素优化

- **应用优化**：在当前素材中添加结果图层，保持文件名和画布尺寸；相应原图层隐藏保留，一次撤销即可恢复。选择活动图层作为来源时，结果保持源层的混合模式、不透明度、显隐状态和堆叠位置。
- **工作区批量应用**：冻结开始时的参数、来源方式和素材列表，逐张更新原文档；工作区素材数量不增加，每张文档分别保留一次撤销记录。面板显示进度、成功数量和跳过原因，可停止处理；切换到其他模式也会停止未完成的队列。
- 处理中已修改或关闭的目标会跳过；超过图层或像素预算时，不会提前隐藏原图层。已达 100 张素材的工作区仍可原位批量应用。
- **创建基础像素素材／批量创建优化素材** 继续提供新增文档的方式。应用只更新工作区编辑内容，写回图片文件仍需执行保存或导出。

## 共享素材与参考

素材工作区包含多张独立图片。每张图片有自己的图层、活动图层和图像历史；拼接场景、优化参数和共享参考属于整个工作区。

参考点、水平线和垂直线可设置名称、精确坐标、颜色、显隐、锁定和吸附；支持点击画布放置，或从绘画标尺拖出参考线。

- **像素坐标**：不同图片使用相同的像素位置，适合同尺寸素材。
- **相对比例**：按基准尺寸的比例映射到当前图片，适合不同尺寸素材。
- **拼接场景**：共享参考以场景原点或内容边界映射显示，随参考定位模式变化。
- **辅助标记**：参考点、参考线、网格和视口框不写入导出的图片像素。

参考随工作区项目保存，也可单独导出/导入 JSON。在已授权的工作目录中，还可保存 `.paint-guides.json`。

## 绘画与精修功能

- 铅笔、9 种画笔样式、橡皮、容差填充、取色、前景色/背景色及 HEX/RGB/HSV 颜色编辑。
- 文字、字体与样式、24 种形状、轮廓和填充、多边形与曲线。
- 矩形/自由选区、移动与缩放、剪切、复制、粘贴、透明选择、反选和裁剪。
- 图片/画布尺寸调整、百分比尺寸、保持比例、最近邻或平滑重采样、旋转、翻转、倾斜和反色。
- 图层新增、复制、删除、重命名、排序、合并、显隐、锁定、不透明度和 8 种混合模式。
- 缩放、实际尺寸、适应窗口、平移、标尺、清晰像素显示和可配置间距的网格。
- 当前图层颜色调整及原图、柔和、暖调、黑白预设；锐化保持每个像素的透明度。
- 11×11 像素放大镜、HEX/RGBA/坐标、前景取样；导航器点击/拖动定位；点击历史步骤恢复图片。

精修中的亮度分布是缩略采样预览，不是完整图像的精确像素统计。锐化可能增加颜色数量，与优化模式的限色处理用途不同，应按素材需要选用。

## 文件格式与完整工程

| 用途 | 格式与说明 |
| --- | --- |
| 图片导入 | PNG、JPEG、WebP、BMP、GIF、SVG、AVIF，解码支持取决于浏览器 |
| 绘画图片导出 | PNG、JPEG、WebP、BMP、静态 GIF |
| 拼接图片导出 | PNG、JPEG、WebP；提供范围、倍率、留白和透明背景选项 |
| 像素转换导出 | PNG、SVG；支持批量转换结果 ZIP，保留透明度 |
| 像素优化导出 | 透明 PNG，支持整数倍率 |
| 批量图片导出 | ZIP，保存工作区中的素材图像 |
| 完整工作区 | `.paintspace` JSON，包含图层像素、图片元数据、混合模式、共享参考、工作区设置、拼接源图与场景、像素转换与优化参数 |
| 单独参考 | 参考 JSON 或目录中的 `.paint-guides.json` |

图片格式会合并可见图层；继续分层创作应同时保存 `.paintspace`。完整工程保存已经应用的编辑，不包含尚未确认的精修预览。

### 旧站工程导入

- **旧画境 `.paintspace`**：恢复图片、图层、参考和旧版设置；旧文件没有的新模式数据使用默认状态。
- **旧拼境 `.pinjing`**：恢复源图片和拼接场景。使用统一工程保存后，可与其他模式的数据一并保留。
- **旧 Pixelroom `.pixelroom` 或其 JSON 工程**：保留分层、图层名称、可见性、锁定、不透明度和混合模式。原有位置、缩放、旋转及颜色滤镜会烘焙到每个图层的像素中，原始参数不再单独可编辑。
- **Pixel Perfect Lab**：优化算法和参数界面已合入，可导入原始图片重新处理。旧站浏览器状态不会跨站点自动读取。

旧站本机草稿受浏览器站点隔离保护。迁移时应先在原站导出工程或图片，再在统一工作台中导入。重新打开工程会建立新的历史起点：撤销列表保留在当前会话中，不随工程文件持久化。

## 文件夹保存与草稿

支持目录访问的浏览器会在用户选择并授权工作目录后，尝试把编辑结果保存到对应文件。浏览器不支持、没有权限或嵌入环境受限时，使用文件夹导入和下载保存；不保证可以直接写回真实磁盘。

目录读写需要安全上下文、浏览器支持和用户授权。部署后可使用桌面版 Edge 或 Chrome 独立打开站点；恢复项目不会恢复系统目录写入权限，需要重新选择目录。

IndexedDB 自动草稿用于恢复当前浏览器中的工作。清除站点数据、浏览器存储不足或切换浏览器都会影响草稿可用性，因此正式作品应主动保存工程文件和输出图片。

## 快捷操作

- 绘画/精修：`Ctrl/Cmd+S` 保存当前图像；`Ctrl/Cmd+Z` 撤销；`Ctrl/Cmd+Y` 重做；`Ctrl/Cmd+C/X/V` 复制、剪切和粘贴。
- 像素转换/拼接/优化/扩边：`Ctrl/Cmd+S` 保存完整工作区工程。
- 透明扩边：`Ctrl/Cmd+Z` 撤销当前素材的编辑，`Ctrl/Cmd+Y` 或 `Ctrl/Cmd+Shift+Z` 重做。
- 绘画工具：`B` 画笔、`P` 铅笔、`E` 橡皮、`F` 填充、`I` 取色、`T` 文字、`M` 矩形选区、`L` 自由选区、`H` 平移。
- 绘画视图：空格拖动平移，滚轮缩放，`Shift` 约束绘图，`X` 交换前景色与背景色。
- 浮动选区/多边形：`Enter` 完成；`Escape` 取消当前操作。

不同模式使用适合自身的工具和快捷键。完整说明见页面帮助及工具提示。

## 本地运行

在仓库根目录运行静态服务器即可，无需安装 npm 依赖或执行构建：

```bash
python3 -m http.server 8080 --bind 127.0.0.1 --directory dist
```

打开 `http://127.0.0.1:8080`。必须通过 HTTP/HTTPS 提供 ES 模块和 Worker，不能直接双击 HTML 使用 `file://` 运行。停止本地服务使用 `Ctrl+C`。

Sites 部署入口由 `.openai/hosting.json` 指向 `dist`。发布时应同步完整源码及全部模块文件，不能仅复制 HTML。

## 适用范围与限制

- 这是独立实现的网页绘画工具，不是 Microsoft Paint 官方产品，也不宣称与任何 Windows 版本逐项完全一致。
- 没有接入 Microsoft Cocreator、Image Creator 或云端生成式编辑。按颜色去背景使用本地连通区域算法，适合相对纯色背景。
- GIF 导入取静态帧，导出为静态 GIF；没有动画时间轴或系统级“设为桌面壁纸”功能。
- 单张绘画画布每边最多 8192 像素，且总面积受约 3200 万像素限制；模式各自还有导入、图层、输出和累计像素预算。大图、多图层和高倍率导出会增加浏览器内存占用。
- 历史记录受步数和内存预算限制，大图的可回退步骤可能较少。工程重开和草稿恢复保留编辑内容，不恢复此前会话的完整撤销时间线。
- 拼接返回绘画时，场景变换会成为输出图层中的像素；完整工程仍保留可继续摆放的拼接场景。
- 融合不自动移动原站浏览器本机数据，也不自动删除原站点。
