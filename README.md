# 画境 · Paint Studio

一个中文、浏览器本地运行的多图片绘画工作台。采用 Paint 熟悉的工具分组，并加入工作区级共享参考点、参考线和多文档编辑。

## 开始使用

1. 点击右上角 **打开工作目录**。在支持文件系统访问 API 的浏览器中，授权选择的目录后可以读取图片并保存回对应文件；不支持时使用文件夹导入与下载保存。
2. 在左侧素材列表或顶部标签中选择要编辑的图片。每张图片拥有自己的图层与撤销记录。
3. 在右侧 **共享参考** 中选择参考点、水平线或垂直线，然后在画布上放置；也可以从标尺拖出参考线。
4. 选择 **像素坐标**，可让同尺寸素材使用同一个像素位置；选择 **相对比例**，可在不同尺寸素材上沿用相同的比例位置。
5. 使用 **导出图片** 保存合成结果。使用文件菜单中的工作区项目功能，可保存或恢复全部图片、图层和参考。

## 编辑功能

- 多文档标签、素材缩略图与搜索、图片拖入、新建画布。
- 铅笔、9 种画笔样式、橡皮、容差填充、取色器、前景色与背景色、自定义 HEX / RGB / HSV 颜色。
- 文字、字体与样式、24 种基础形状、轮廓及填充、多边形和曲线。
- 矩形与自由选区、移动、缩放、剪切、复制、粘贴、透明选区、反选和裁剪。
- 图片与画布尺寸调整、像素或百分比尺寸、保持比例、旋转、翻转、倾斜、反色。
- 图层新增、复制、删除、重命名、上下移动、合并、显示、锁定与不透明度。
- 缩放、适应窗口、实际尺寸、画布平移、标尺、像素网格和全屏。
- 独立图片撤销 / 重做、共享参考撤销 / 重做、本机 IndexedDB 草稿恢复。

## 共享参考

参考点和参考线属于整个工作区，不属于单张图片。可以修改名称、精确坐标、颜色、显示状态及锁定状态；绘图可吸附到参考。辅助标记不会出现在图片导出中。

工作区项目保存共享参考。也可单独导出和导入参考 JSON，或在已授权的工作目录中保存 `.paint-guides.json`。

## 文件格式

- 导入：PNG、JPEG、WebP、BMP、GIF、SVG、AVIF，具体解码支持取决于浏览器。
- 导出：PNG、JPEG、WebP、BMP、静态 GIF。
- 批量导出：ZIP。
- 完整项目：`.paintspace` JSON 文件，包含全部图层像素、图片信息、共享参考和工作区设置。
- 图片保存不保留图层；继续分层编辑请同时保存工作区项目。

## 快捷操作

常用快捷键包括 Ctrl/Cmd+S 保存、Ctrl/Cmd+Z 撤销、Ctrl/Cmd+Y 重做、Ctrl/Cmd+C/V 复制粘贴；B 画笔、P 铅笔、E 橡皮、F 填充、I 取色、T 文字、M 选区、H 平移。按住空格拖动画布，Shift 约束绘图，X 交换前景色和背景色。完整说明见页面右上角帮助。

## 适用范围

- 这是独立实现的网页绘图工具，不是 Microsoft Paint 官方产品，也不宣称与任一 Windows 版本逐项完全一致。
- 未接入 Microsoft Cocreator、Image Creator、生成式填充或其他需要云服务、账号或专用硬件的微软功能。背景移除使用本地颜色连通算法，适用于背景颜色较一致的素材，不是 AI 主体识别。
- GIF 以首帧导入并导出静态 GIF；不提供动画时间轴。
- 浏览器文件夹读写需要安全上下文、支持的浏览器和用户授予目录权限。推荐在桌面版 Chrome 或 Edge 中打开部署后的 HTTPS 地址。原生系统级操作（例如设为桌面壁纸）不属于网页功能。
- 所有图像处理均在浏览器中进行；代码不将用户图片上传到服务器。本机草稿依赖当前浏览器的站点数据，不能替代主动保存的项目文件。
- 单张画布每边最大 8192 像素，且总像素最多 3200 万；导入数量与累计像素设有上限以降低浏览器内存压力。历史记录受步数及内存预算约束。

## 项目结构

`dist/index.html` 和 `dist/style.css` 构成界面；`app.js` 管理交互；`core.js` 与 `drawing.js` 负责像素和图层；`io.js` 处理文件与编码；`autosave.js` 管理本机草稿；`demo.js` 生成初始示例。没有前端依赖、外部字体或构建步骤。

部署入口由 `.openai/hosting.json` 指向 `dist`。需要通过 HTTP/HTTPS 静态服务器运行 ES 模块，不应直接以 `file://` 打开。

## 已完成的验收

浏览器中验证了新建画布、笔刷绘制、形状、填充、撤销与重做、选区移动、文字、切换图片、共享参考像素定位及相对比例定位、本机草稿恢复、PNG 导出。导出 PNG 经独立像素读取确认了尺寸、颜色、透明区域和参考标记不参与输出。

图像引擎、GIF 编码与文件格式另有本地检查。完整项目通过了 2 个文档、5 个图层、3 个参考的真实 PNG 编码与解码往返测试：逐层 RGBA、合成像素、图层状态、文档元数据、共享参考和设置均一致，文件 MIME 为空时也可正常读取。云预览为 HTTP，未对用户真实磁盘执行目录写入验证。完整项目下载在云浏览器中没有提供可验证的下载事件，因此保留可见的下载链接作为手动下载入口，不将该事件检查记为通过。
