# 画境 Pro · 专业绘画工作台

**简体中文** | [English](README.en.md)

画境 Pro 是在浏览器中运行的图片编辑与像素创作工具，提供像素转换、绘画、精修、拼接、瓦片画布、切图、像素优化和透明扩边八种模式。各模式共用素材工作区，处理结果可直接继续编辑。

应用使用原生 JavaScript ES 模块、Canvas 2D、Web Worker 和 IndexedDB。图片在当前浏览器中处理；应用代码不会把用户图片上传到服务器。没有前端依赖安装、外部字体或构建步骤。

## 程序启动

程序文件位于 `dist` 目录。先安装 **Python 3**，无需安装 npm 依赖或执行构建。

### Windows

双击程序目录中的 **`dist/start.bat`**，保持命令窗口打开，然后在浏览器访问 <http://127.0.0.1:8080>。脚本依次检测 `py -3`、`python` 和 `python3`，使用可用的 Python 3。

也可以从仓库根目录运行，并按需指定端口：

```powershell
.\dist\start.bat
# 8080 端口被占用时，改用 8090：
.\dist\start.bat 8090
```

### macOS / Linux

在仓库根目录运行：

```sh
sh ./dist/start.sh
# 可选：指定其他端口
sh ./dist/start.sh 8090
```

两个脚本都以自身所在的程序目录为服务根目录，从其他路径启动也可使用；默认只监听本机 `127.0.0.1:8080`。指定其他端口时，在浏览器打开对应地址。按 **Ctrl+C** 停止服务。

### 手动启动与部署

也可在仓库根目录直接启动静态服务器：

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory dist
```

Windows 可将 `python3` 换成 `py -3` 或 `python`。必须通过 HTTP/HTTPS 提供 ES 模块和 Worker，不能直接双击 HTML 使用 `file://` 运行。目录读写功能建议使用桌面版 Edge 或 Chrome，并在应用中授权工作目录。

静态部署时以 `dist` 为站点根目录，上传其中完整的 HTML、JavaScript、CSS 和图标文件。Sites 部署入口已由 `.openai/hosting.json` 指向 `dist`。

## 深色棋盘格与画布裁剪

绘画、精修和透明扩边的背景选择器提供 **深色棋盘格**，交替使用 `#252B33` 与 `#3A424D`。三处预览共用工作区背景设置，随本机草稿和工作区项目保存。背景仅绘制在预览显示层，不改变素材透明像素，也不写入导出的图片。

在 **透明扩边 → 画布裁剪** 中，拖动结果画布的四边或四角可调整画幅。向外增加透明区域，向内裁去超出画幅的部分；拖动时显示目标边界和尺寸，按 Esc 可取消，松开后一次提交到当前素材，可用工作台的撤销与重做恢复。裁剪沿用全部图层处理流程，支持创建副本和工作区批量处理；批量时按相同的四边增减像素应用到各素材，不缩放原像素。

## Liquid Glass 外观

八种工作模式共用一套明暗配色、间距和圆角规则。导航、工具栏及小型浮动控件采用半透明材质、顶部镜面内高光、方向性边缘反光与悬浮投影；素材、参数和图层面板使用实色表面。画布、源图、色板和像素预览不施加玻璃滤镜，保留真实颜色与原有像素渲染。

- **切换外观**：点击右上角的外观图标，选择「跟随系统」「浅色」或「深色」。默认跟随系统；设置只作为当前浏览器偏好保存，与素材、草稿和 `.paintspace` 工程独立。
- **统一几何**：主要面板采用 24px 圆角与 8px 间距，内层圆角按父容器减去内边距递进；导航、按钮和标签页使用胶囊形，紧凑字段采用固定小圆角。字体优先使用设备自带的系统字体。
- **响应式反馈**：支持精细指针的设备上，玻璃边缘高光随指针位置变化；按钮具有轻微按压反馈，菜单与主对话框使用弹簧进入效果。纵向滚动素材和设置列表时，顶部栏适度收缩，向上滚动或使用顶部键盘焦点时展开；不改变模式顺序或图像数据。
- **简化效果**：外观面板中的「简约效果」切换为实色表面并关闭动态。系统减少透明度、增加对比度和减少动态设置会优先生效；强制颜色模式继续显示真实的选色色块。外观面板支持方向键、Home/End、Enter/空格和 Escape，其键盘事件不触发绘画快捷键。
- **性能与降级**：模糊仅用于有限的控件表面，设置面板不叠加模糊。低并发设备、节省流量设置或持续偏慢的交互会使用更轻的玻璃效果；指针离开、窗口失焦或页面隐藏后停止相关帧任务。不支持背景滤镜时使用实色表面，不支持遮罩时保留内阴影高光。

这是 CSS 光学近似实现，使用 `backdrop-filter`、渐变边缘与内阴影，不引入 SVG 位移、WebGL 或 DOM 纹理采样。外观控制器位于 `dist/liquid-glass.js`，首次主题初始化位于 `dist/liquid-theme-init.js`；新样式在原有模式样式之后加载。

外观行为可用 `node tests/liquid-glass.test.mjs` 验证，覆盖首次主题、系统与手动偏好、无障碍设置、键盘与焦点隔离、方向性高光、滚动阈值、性能降级和清理。此测试使用最小 DOM 与可控帧时钟，不代替真实浏览器的光学效果、触摸交互和最终布局验收。

## 八种工作模式

顶部导航默认按 **像素转换 → 绘画 → 精修 → 拼接 → 瓦片画布 → 切图 → 像素优化 → 透明扩边** 排列。长按任一功能约 0.4 秒，拖到另一功能的高亮框上松开，即可交换两者位置；当前模式保持不变。Esc、拖出功能栏后松开或窗口失焦会取消操作。窄屏可快速横向滑动浏览，长按拖到边缘时自动滚动。焦点位于功能入口时，也可用 **Alt + ← / →** 与相邻入口交换。顺序作为当前浏览器偏好独立保存，刷新后保留；已有自定义顺序的浏览器会将新增模式追加在最后。

| 模式 | 主要能力 | 与工作区的连接 |
| --- | --- | --- |
| **像素转换** | 图片像素化、限色、三种采样、输出缩放、透明度、前后对比与 PNG/SVG 导出 | 读取当前素材的可见图层；保存为新素材后可直接进入绘画，也可批量新增或转换为 ZIP |
| **绘画** | 多文档标签、分层绘画、整层移动、文字与形状、选区、裁剪、变换、填充、共享参考 | 每张素材拥有独立图层和操作历史，可从工作目录或文件导入 |
| **精修** | 亮度、对比度、饱和度、色相、模糊、预设、锐化、像素检查、导航器和历史 | 直接编辑当前素材的活动图层；参数先预览，应用后写回图层 |
| **拼接** | 无限场景、多图自由摆放、卡槽组装、多选、缩放旋转、翻转、对齐与自动排列 | 从统一素材区添加图片；拼接结果可送回绘画，继续分层编辑 |
| **瓦片画布** | 固定画布、自定义尺寸与高清预设、素材拖动与旋转、指定像素块分割、网格吸附、选点测量、PNG/ZIP 导出 | 独立保存画布与图层，复用工作区素材及卡槽能力；可送回绘画 |
| **切图** | 可拖动横竖切线、精确像素坐标、均分、切块预览；按行列等分精灵帧，可补透明边缘 | 读取当前素材的可见图层；确认后整组加入独立素材，保留来源，可直接绘画、拼接或导出 |
| **像素优化** | 网格识别与偏移、采样、限色、透明边缘、孤点清理、滑杆/并排/结果对比、整数倍率导出 | 读取当前图片或图层；结果可成为新素材或结果图层，也可逐张批量处理 |
| **透明扩边** | 常用宽高比、画布倍数、目标尺寸、自动内容居中，以及五种算法和按宽高、百分比、单边、长边缩放 | 直接应用当前素材或整个工作区，保留图层；也可创建副本、导出透明 PNG |

`workbench.js` 统一协调八种模式。像素转换以原图快照和独立 Worker 生成结果；绘画和精修使用同一组 `PaintDocument`；拼接和瓦片画布分别保留自己的源图片与变换场景；切图从源图快照生成整组独立文档并一次性提交；优化保留参数，通过 Worker 计算；透明扩边读取素材快照并对全部图层统一平移或逐层重采样。各模块通过应用接口读取素材、提交结果和保存配置。

## 开始使用

1. 点击 **打开工作目录** 或 **导入图片**，也可以直接拖入图片。左侧素材列表和顶部文档标签选择当前图片。
2. 需要将图片转为像素风格时，先打开 **像素转换**，调节参数并对比结果，点击 **保存新素材并进入绘画** 继续编辑。
3. 在 **绘画** 中编辑素材，每张图片分别保留图层、查看位置和当前会话的撤销记录。通过左侧素材列表或顶部标签切换图片时沿用当前查看倍率，关闭当前图片后也保留该倍率；首次查看的素材按当前倍率居中显示。需要重新取景时可点击 **适应窗口** 或 **1:1**。
4. 在 **精修** 中调节活动图层。滑杆只生成临时预览，点击 **应用调整** 才写回；重置、切换目标或离开相关面板/模式会取消未应用的预览。
5. 在 **拼接** 中添加工作区素材，自动排列、自由摆放，或用右侧 **卡槽组装** 连接主体与配件。结果可以返回绘画工作区继续分层编辑。
6. 在 **瓦片画布** 中设置固定画布和每块瓦片的像素宽高，加入素材布局，使用 **选点与测量** 检查坐标与区域尺寸，再导出整张 PNG 或分割 ZIP。也可通过 **图像 → 瓦片画布 / 分割** 打开。
7. 在 **切图** 中拖动横竖切线，或切换 **精灵帧切图** 输入行数、列数，检查预览后点击 **确认切图并加入工作区**。也可通过 **图像 → 切图 / 精灵帧** 打开。
8. 在 **像素优化** 中对比原图与结果，确认参数后点击 **应用优化** 更新当前素材，或用 **工作区批量应用** 更新工作区中的各张素材；也可以创建新素材或导出 PNG。
9. 在 **透明扩边** 中选择宽高比、画布倍数或目标尺寸补透明边；需要改变素材像素尺寸时，选择 **图像缩放**，设置尺寸方式与采样算法。指定宽高默认 `48 × 48`，可直接拉伸、等比补透明、等比裁切或适应边界框。预览后应用到当前素材或工作区，也可创建副本或导出 PNG。也可通过 **图像 → 透明扩边 / 自动居中** 打开。
10. 使用 **导出图片** 保存最终图像；使用 **保存工作区项目** 保留完整编辑数据。

## 双模式切图与精灵帧

顶部 **切图** 使用当前选中素材的可见图层合成图。来源的像素、图层和历史保持原状，切割结果为独立单图层 PNG 素材。标尺、切线、编号和缩略图选框只用于预览，不写入切块。

### 自由切线

- 初始提供一条居中的竖向切线和一条横向切线。拖动调整位置，也可在右侧输入整数像素坐标；每方向支持 0–40 条切线。
- “＋”在当前最大空隙中间添加一条，“−”删除最近添加的一条；每条也可独立删除。“均分”按当前切线数均匀排列，“清空切线”恢复完整图片一块。
- 默认拖动吸附整数像素。无论是否开启吸附，实际切割都使用四舍五入后的整数像素边界，预览线与输出一致。重复、重合及图片边缘的切线合并，不产生空尺寸图片。
- 下方缩略图按从左到右、从上到下排列；点击缩略图可高亮对应区域并查看原图坐标与实际宽高。放大、1:1、适合视图和空格/中键拖动只改变预览。

### 精灵帧切图

输入的是**行数和列数**，每格生成一帧，行列各支持 1–100，并且不能超过源图对应方向的像素数。比如 1024 × 512 图片设为 4 行、8 列，会生成 32 张 128 × 128 帧。

默认要求源图宽度可被列数整除、高度可被行数整除。不能整除时会提示调整参数；勾选 **补透明边缘后等分**，按 `ceil(宽度/列数)` 和 `ceil(高度/行数)` 计算统一帧尺寸，向右侧和底部扩展透明边缘后等分，不缩放原像素。补边可能产生全透明末帧，这些帧仍按原行列顺序保留。两种切图模式分别保留切线和行列设置。

### 确认与工作区

- 点击 **确认切图并加入工作区** 后先完成整组构建，再一次性加入左侧素材区。原素材继续选中，搜索筛选会清空并滚动显示新增结果，点击任意新素材即可继续编辑。
- 自由切图命名如 `原名_切图_r01c01.png`；精灵帧命名如 `原名_帧_001_r01c01.png`。名称冲突自动添加编号，保留半透明像素，每张有独立的初始操作历史。
- 生成期间可用取消按钮或 Esc 停止；取消、无效参数、容量不足或来源变化均不提交半组结果。生成时暂停素材切换、全局修改及导入，但仍可保存工程。
- 沿用工作区最多 **100 张素材**，确认前计算可用数量。切图整组新增按现有图层加新增图层合计 **64 Mi 像素**检查容量；源图边长最多 8192、面积最多 32 Mi 像素。预览可计算更多格子，但超过剩余容量时不能确认，下方仅显示前 100 张。
- 当前切图方式、切线、行列、补边和吸附设置随 `.paintspace` 与本机草稿保存。切块作为普通素材参与完整工程保存、拼接、扩边及图片/ZIP 导出。

## 画布网格

绘画与精修画布的底栏提供 **显示网格** 开关和 **间距** 输入。默认关闭显示，间距默认为 **1 px**，可自定义为 **1–1024 px** 的整数。网格只用于预览，不修改图片像素，也不会出现在导出图片中。当网格在屏幕上的实际间距小于 **5 px** 时会暂时隐藏，底栏会提示所需的放大倍率；例如 1 px 网格提示「放大至 500% 显示」。

## 绘画中的图层移动

在右侧图层列表中选中目标，点击 **移动当前图层** 或按 **V**，然后在画布内拖动。上方工具栏和左侧快捷工具也有 **移动图层** 入口。它移动活动图层的原始像素，不需要先框选，也不受“透明选择”背景色选项影响。

- **选择目标**：默认保持右侧选中的图层；开启 **画布点选图层**，或按住 Ctrl/⌘ 点击，可以按非透明像素选中最上方可见图层。锁定图层会被选中并提示解锁，不会透过它误移下面的图层。
- **精确移动**：拖动按整数像素定位；Shift 拖动约束水平或垂直。方向键移动 1 px，Shift + 方向键移动 10 px。虚线框显示当前层的内容范围；空格、中键或 H 仍然平移视图。
- **越界裁剪**：默认允许图层移出画布，松手后自动裁剪并删除画布外的像素；再移回不会找回已裁掉的内容，可通过撤销恢复。整层移出会清空该层像素并保留图层。方向键移动遵循相同规则。需要边缘保护时，可手动开启 **保持内容在画布内**。旧草稿与旧工程首次恢复时采用新的默认行为，此后手动选择的保护设置随草稿与工程保存。
- **提交与取消**：拖动过程只有预览，松手后一次性提交一个图层移动记录。Esc、丢失指针捕获、窗口失焦或切换文档/图层/工具/模式会取消尚未完成的拖动。点击不移动不会新增历史；移动结果支持撤销、重做、草稿和工程保存。
- **独立图层**：其他层的像素、层次、显隐、不透明度与混合模式保持；隐藏、锁定和空白图层会给出明确提示。

## 图片像素转换

参考「PixelTool · 本地像素画生成器」的处理流程，使用当前素材的可见图层合成图建立原图快照。可以在面板导入图片或文件夹，也可从左侧切换素材；参数变化始终重新处理输入快照，不叠加处理上一次转换结果。

| 参数 | 范围与行为 |
| --- | --- |
| 像素块大小 | 2–32 px，默认 8 px |
| 最大颜色数 | 2–256 色，默认 128；界面显示结果的实际 RGB 颜色数 |
| 输出缩放 | 10–100%，默认 100%；先缩放原图，再采样像素块 |
| 采样方法 | 主色调、平均值、中位数 |
| 网格对齐 | 默认开启；输出宽高向上补齐为像素块大小的整数倍，最后一格延展至完整块。关闭时保留缩放后的尺寸，末格可小于完整块 |
| 保留透明背景 | 默认开启；完全透明像素不参与 RGB 统计，半透明区域参与透明度加权。关闭时先合成到白底 |

- **预览与输出一致**：支持前后对比、仅结果和原图视图，以及缩放、平移和网格辅助。原图按输出比例显示以便对照；网格标记不会导出。右侧和底部的源像素都参与采样，PNG 与 SVG 使用相同的像素块几何。
- **保存为新素材**：点击 **保存为工作区新素材** 增加一张结果，保持当前原素材选中；点击 **保存新素材并进入绘画** 则选中新素材并打开绘画。两种操作均不覆盖原图，结果以独立单图层文档继续编辑。
- **PNG / SVG 导出**：PNG 保留转换结果的透明度；SVG 以矩形表示像素块，保留透明与半透明，并合并同一行连续的相同色块。
- **工作区批量转换**：固定开始时的素材列表、参数和导出格式，每张图片独立计算输出尺寸。可批量保存新素材，或把转换结果打包为 PNG/SVG ZIP；新增结果不会再进入本轮队列。停止或离开面板会取消后续处理，已保存的新素材保留；已修改或关闭的来源会跳过。
- **工程与草稿**：转换参数、预览方式、格式和网格显示状态随 `.paintspace` 与本机草稿保存。转换预览可按素材和参数重新生成；正式保留结果时使用保存新素材或下载。
- **处理限制**：缩放后的单张输入最多 16,777,216 像素；SVG 最多 100,000 个合并后矩形，超限时需增大像素块或改用 PNG。工作区最多 100 张素材，批量新增前会检查剩余位置；导出 ZIP 不占用新增素材位置。

## 固定尺寸瓦片画布与选点测量

参考 `16x16布局查看.html` 的固定画布、网格交点吸附、素材锚点及两点量取方式。参考中的 16×16 表示网格行列数；本功能按用户指定的 **每块像素宽 × 高** 分割，并据此计算行列数。

| 快选 | 画布宽 × 高 |
| --- | --- |
| 720P | 1280 × 720 px |
| 1080P | 1920 × 1080 px |
| 2K / QHD | 2560 × 1440 px |

- **尺寸与素材**：默认 1920×1080 透明画布，可输入自定义宽高或交换宽高；普通“新建画布”弹窗也提供以上快选。改变画布只调整输出边界，素材尺寸不变，越界内容继续保留在场景中。加入素材保持原尺寸，提供“居中素材”和“适配画布”操作。空画布也能保存、导出或送回绘画。
- **拖动移动**：加入素材后自动进入“移动素材”，关闭此前的平移或选点模式并保留测量结果。点击画布上的素材后直接拖动，`V` 返回移动工具；Shift 多选后可整体移动，拖动时按 Shift 约束为横向或纵向。小素材在缩小视图中不显示或命中缩放角点，避免拖动变成缩放；放大后恢复角点缩放。右侧顶部“素材操作”可精确输入单个素材的 X/Y。
- **旋转素材**：点击浮动工具条或右侧的“旋转素材”，或按 `R`，在素材本体左右拖动调整角度；也可拖动选框上方的旋转圆环。按住 Shift 按 15° 吸附，旋转时显示角度。右侧提供任意角度输入、−90°、+90°和角度归零，作用于单个可见、未锁定素材。旋转保持原素材宽高与卡槽连接，配件按既有对接约束跟随；移动已对接配件会解除连接，或在松开时连接新的空槽。
- **移动与旋转历史**：拖动松手后提交一次历史，可撤销、重做；Escape、指针取消、意外失去指针捕获、窗口失焦或切换模式时恢复本次拖动前状态。位置、尺寸和角度随草稿与完整工程保存，导出和瓦片分割使用变换后的像素；选框和旋转手柄不写入输出。
- **网格与吸附**：默认每块 64×64 px，提供 16、32、48、64、128、256 方形快选及非正方形自定义块。预览显示总列数、行数和块数；格号以“列,行”显示。拖动可用素材左上角、左下角或中心吸附最近网格交点；浮动工具条的吸附按钮与右侧“网格吸附”同步，关闭后可自由移动。`Alt` 临时暂停网格与卡槽吸附。最右和最下边界使用真实画布尺寸。卡槽吸附开启且有有效目标时优先处理卡槽，使用独立开关。
- **选点与尺寸测量**：点击“开启选点”或按 `M`，直接在画布或图片上点击 P1、P2。点位吸附最近网格交点，分别显示像素坐标、区域宽高与跨越列/行数，画布显示双色标记与矩形区域。反向选点仍显示正宽高，同一行或列允许零宽/高。第三次点击从 P1 重新开始；“退出选点”保留结果，“清除”仅清测量点。改变画布或块尺寸会清除旧测量，切换网格显示、锚点或导出边缘策略会保留结果。测量是临时视图辅助，不记录图层历史或写入工程。
- **完整画布输出**：“导出整张 PNG”按固定尺寸合成可见图层，保留透明余白；顶部导出面板另提供格式、倍率与图层范围选项。送回绘画也按固定画布裁边，保留独立图层；原瓦片场景仍可继续编辑。网格、格号、测量点、卡槽和共享参考标记均不写入输出像素。
- **实际瓦片分割**：“分割并导出 ZIP”生成每块独立 PNG 和 `layout.json`。默认不足一块的末行/末列补透明至指定块尺寸，也可选择保留实际边缘宽高。可跳过全透明瓦片，任何非零 alpha 都计作内容。文件名如 `tile_r000_c000.png`，按行优先、从 0 开始编号；跳过空白不会重新编号。清单记录原画布尺寸、块尺寸、坐标、实际覆盖范围及导出/跳过数量，便于还原布局。
- **撤销、工程与导出状态**：画布、瓦片参数和图层改动可撤销/重做；完整 `.paintspace` 和本机草稿保存独立瓦片场景，普通拼接场景不受影响。ZIP 开始时冻结整张输出快照，处理中显示进度、阻止编辑和模式切换，可取消后继续编辑或重试。

画布和单块瓦片各边支持 1–8192 整数像素，面积最多 32×1024×1024 像素。单次 ZIP 最多 10,000 块、200 MiB；超过限制会提示增大块尺寸或减小画布，不会静默丢弃边缘像素。

## 拼接中的卡槽组装

参考素材拼装 HTML 的「主体卡槽 + 配件对接点」机制，卡槽可用于任意图片素材，不需要预先分类。

1. 选中主体图层，在右侧 **卡槽组装 → 编辑卡槽** 打开原图预览。点击素材添加卡槽，拖动调整位置，也可输入原图像素 X/Y；每层最多 6 槽，可命名、删除和重置位置。
2. 配件默认以素材中心作为对接点。需要其他安装位置时，选中配件并点击 **对接点**，在原图上点击或输入坐标。
3. 开启 **卡槽吸附** 后，将配件拖近主体空槽（22 个屏幕像素内），画布会高亮候选并提示松开对接。也可从 **配件对接到** 下拉框选择「主体 / 卡槽」，点击 **对接到卡槽**。
4. 每槽最多连接一个配件。拖动只吸附空槽；选择已占用的卡槽后，按钮变为 **替换槽内配件**。替换只解除原配件的连接，原配件仍留在画布原位置。已锁定的配件需先解锁才能替换。

对接约束保持两个锚点的世界坐标重合。主体移动、缩放、旋转或翻转后，配件对接点跟随卡槽位置；配件本身的尺寸、角度、翻转独立控制。一个图层也可同时拥有卡槽并连接到其他主体，系统拒绝循环连接。锁定限制直接编辑，已锁定的配件仍按连接关系跟随主体；隐藏图层不作为拖动吸附目标。

- **自由移动**：拖动已连接配件会先解除原连接；松开时可连接新的空槽。按住 `Alt` 暂停卡槽及边缘/参考线吸附。仅点击配件不会解除连接。方向键微调或更改 X/Y 也会解除该配件的对接。
- **整组处理**：点击 **选中整个组件**，可一起移动或复制。多选主体和配件不会重复平移；复制整组会重新关联复制后的主体。只复制配件时，新副本独立放置。
- **保留位置**：解除对接、替换配件、删除主体或删除卡槽后，相关配件保留当前世界位置。对齐与自动排列会解除所选配件的对接；排列同时将旋转归零。
- **编辑与撤销**：锚点编辑先保存在弹窗草稿中，点击 **保存锚点** 才应用；取消与 Escape 不更改场景。连接、替换、解除、编辑、复制和删除都可撤销/重做；取消画布拖动会恢复整个组件。
- **保存与输出**：卡槽名称、原图相对坐标、对接点和连接关系随完整 `.paintspace` 与本机草稿保存；旧工程没有这些字段时使用空卡槽和中心对接点。图片导出及送回绘画均只输出素材像素，卡槽标记不会写入图片。送回绘画保留分层像素，原拼接场景继续保留可编辑连接。

## 自动透明扩边与图像缩放

透明扩边参考 PNG 填充工具的目标画布流程，自动计算中心，无需在图片上手选中心点。

- **自动内容居中**：扫描可见图层合成图中全部 `alpha > 0` 的像素，以包围盒中点作为内容中心，半透明边缘也计入。完全透明的素材使用画布中心。
- **扩边保持原像素**：宽高比、画布倍率和像素尺寸三种扩边方式扩大画布并进行整数像素平移，原素材不缩放、不裁切；原画布中的既有透明边也完整保留。已有透明边不对称时，自动居中可能需要更大的输出画布。
- **保留图层**：应用时所有图层使用相同偏移，包括隐藏或锁定图层；图层名称、可见性、不透明度和混合模式保持。扩边不会将素材合并成单层。
- **独立预览**：调整参数始终根据读取时的素材快照重新计算，不会随着选择多个比例反复累加扩边。预览中的边框与中心辅助标记不写入导出的 PNG。
- **比例与尺寸**：提供 `1:1、4:3、3:2、16:9、2:1、3:1、4:1、1:2、3:4、9:16` 及自定义比例，另有 `1.25× / 1.5× / 2× / 3× / 4×` 画布倍率和指定像素尺寸；像素尺寸提供 `720p（1280×720）`、`1080p（1920×1080）`、`2K（2560×1440）` 常用分辨率快捷选项，点击同步目标宽高与预览。统一宽高比允许每张图片输出不同尺寸；批量勾选“全部统一为相同像素尺寸”会为有效素材求共同画布。指定目标宽高始终严格执行，目标尺寸不足的图片会提示原因，不缩小或裁切像素。
- **整数像素居中**：奇偶尺寸不匹配时，几何中心允许最多半个像素的偏差，以保持完整像素。按同一宽高比重复计算不会因这一舍入误差不断扩大画布。
- **工作区批处理**：先预览逐张尺寸，再应用；各图使用自身内容中心，分别记录历史，可在对应素材中撤销或重做。中途停止后，同一参数下续跑会保留本批次快照并跳过已完成项，避免倍率累计。扩边参数随工作区项目和本机草稿保存。全透明素材若设置额外留白，会以原画布作为留白主体。

### 自定义图像缩放

在右侧 **扩边与缩放 → 图像缩放** 中选择尺寸方式与采样算法，支持放大和缩小。最终输出每边为 `1～8192` 的整数，总像素不超过 `32 × 1024 × 1024`；工作区总图层容量限制继续生效，超限会提示调整参数。

| 尺寸方式 | 计算规则 |
| --- | --- |
| **指定宽高** `dimensions` | 默认 `48 × 48`，宽高独立输入；另有 `16 / 32 / 48 / 64 / 128 / 256` 方形快选，配合下表四种适配方式 |
| **百分比 / 倍率** `percent` | 默认 `100%`，允许 `0.1～3200%`；按每张素材自己的原宽高计算，`200%` 为宽高各放大两倍 |
| **固定宽度** `width` | 输入目标宽度，等比计算高度 |
| **固定高度** `height` | 输入目标高度，等比计算宽度 |
| **固定长边** `long-edge` | 默认长边 `256px`，允许 `1～8192px`；横图固定宽度、竖图固定高度，另一边等比计算 |

仅 **指定宽高** 使用以下适配方式；百分比、固定单边与固定长边直接输出各素材的实际等比尺寸，不额外补边。

| 指定宽高的适配方式 | 输出行为 |
| --- | --- |
| **直接拉伸** `stretch`（默认） | 完整原画布填满目标宽高；比例不同时会拉伸 |
| **等比完整 · 居中补透明** `contain` | 完整保留原画布，等比缩放后居中放入目标透明画布；例如 `96 × 32 → 48 × 48` 得到 `48 × 16` 内容，上下各补 `16px` |
| **等比填满 · 居中裁切** `cover` | 填满目标尺寸，按原画布中心裁去超出比例的两侧或上下部分；直接采样原图裁切范围，不先生成超大中间画布 |
| **等比适应 · 不补边** `inside` | 将输入宽高作为边界框，输出实际等比尺寸；例如 `96 × 32` 适应 `48 × 48`，输出为 `48 × 16` |

尺寸计算以完整原画布为范围，包含已有透明边；主体居中和最少留白参数只用于扩边。等比尺寸沿用 Python `round` 的最近偶数取整规则（如 `2.5 → 2`、`3.5 → 4`），极小尺寸至少保留 `1px`。补边使用整数偏移居中，奇数空隙多出的一个像素留在右侧或下侧。

| 采样算法 | 特点与用途 |
| --- | --- |
| **最近邻** `nearest`（默认） | 直接选取原像素的 RGBA，不混合颜色；适合像素画、图块与精灵，缩小时可能舍弃细线 |
| **面积平均** `area` | 按输出像素覆盖的源像素面积加权，主要用于缩略图与大幅缩小，会混合颜色 |
| **双线性** `bilinear` | 对相邻像素加权，产生较柔和的平滑过渡 |
| **双三次** `bicubic` | 使用三次插值，在平滑与锐度之间折中；高对比边缘可能出现轻微光晕 |
| **Lanczos 3** `lanczos3` | 使用三瓣 Lanczos 滤波保留细节，计算量较大；高对比边缘可能出现振铃或光晕 |

这些算法由同一 RGBA 采样模块实现，不依赖浏览器的平滑开关。最近邻保留旧版 Pillow 采样边界行为；其余算法对颜色和透明度一起滤波，内部使用预乘 alpha，避免透明像素的隐藏颜色混入可见边缘。平滑算法会改变颜色及边缘透明度，不会将半透明像素作为粘贴蒙版重复衰减。

- **每层独立处理**：全部图层使用相同尺寸、裁切范围和算法，再按原图层关系合成预览与 PNG。名称、顺序、隐藏/锁定、不透明度和混合模式保留；不会先合并图层再缩放。每张素材一次撤销可恢复尺寸与各层像素。
- **快照与预览**：调参始终从本次读取的原图快照计算；“重新读取”以当前素材建立新起点。预览、应用、创建副本和 PNG 导出共用采样路径；异步计算的过期结果不会替换新的预览。
- **异步批量应用**：先预览各张尺寸，再按本批次参数逐张处理。指定宽高的拉伸、补边和裁切得到统一尺寸；适应边界框、百分比、单边与长边方式可能得到不同尺寸。可停止处理，未完成的当前素材不提交，已完成素材保留并分别支持撤销。相同批次续跑跳过已完成项；更改参数后重新分析。工作区 PNG ZIP 导出已应用的结果。
- **预览背景**：**深色摄影棚 / 透明棋盘格 / 透明背景** 都是查看设置，不填充图片背景，不改变素材透明度，也不进入 PNG。边框、中心和范围辅助标记同样不写入输出。

共享参考仍使用工作区既定规则：像素坐标参考保持原坐标，相对比例参考按各素材当前画布映射。单张或批量扩边、缩放不会改写全局参考配置，参考标记不进入 PNG。透明扩边依据透明度识别范围，不会自动抠除白色或其他不透明背景。尺寸方式、适配方式和算法随工作区项目及本机草稿保存。

## 应用像素优化

- **应用优化**：在当前素材中添加结果图层，保持文件名和画布尺寸；相应原图层隐藏保留，一次撤销即可恢复。选择活动图层作为来源时，结果保持源层的混合模式、不透明度、显隐状态和堆叠位置。
- **工作区批量应用**：冻结开始时的参数、来源方式和素材列表，逐张更新原文档；工作区素材数量不增加，每张文档分别保留一次撤销记录。面板显示进度、成功数量和跳过原因，可停止处理；切换到其他模式也会停止未完成的队列。
- 处理中已修改或关闭的目标会跳过；超过图层或像素预算时，不会提前隐藏原图层。已达 100 张素材的工作区仍可原位批量应用。
- **创建基础像素素材／批量创建优化素材** 继续提供新增文档的方式。应用只更新工作区编辑内容，写回图片文件仍需执行保存或导出。

## 共享素材与参考

### 拖动画幅边界

绘画和精修模式中，画幅四边和四角提供固定屏幕大小的拖拽手柄，整条边界均可拖动。四边调整单个方向，角点同时调整宽高；对边固定，原有像素不缩放。向外扩展的部分透明，向内收缩会裁去边界外的内容，包括隐藏和锁定图层，所有图层名称、显隐、锁定、不透明度与混合模式保持。

拖动时只预览新边界与实时尺寸，不反复修改像素；松开鼠标一次提交「调整画幅」历史，可撤销或重做。Esc、失焦、取消指针、切换素材/工具/模式或缩放视图会取消未提交拖动。手柄聚焦后也可用方向键微调 1px，Shift＋方向键微调 10px。存在选区、使用区域截图或平移工具时暂时隐藏画幅手柄，避免与选区操作冲突。

各边支持 1–8192 整数像素、单张最多 32×1024×1024 像素；工作区总图层像素限制继续生效。共享参考仍采用工作区既定坐标规则；画幅手柄、边框和尺寸提示均不写入导出图片。

### 切换工作目录

「打开工作目录」将新目录作为新的工作区：读取成功后替换原素材，重置旧拼接与瓦片场景、处理参数、选区、剪贴板和素材搜索。共享参考从新目录的参考配置载入；没有配置时清空旧参考。单独「导入图片」继续追加图片。

有未保存修改时会提示先保存工程或继续打开。取消、图片全部读取失败、无效参考配置及切换失败均保留原工作区；较早的异步导入不会混入之后打开的工作区。确认选择的空目录会得到一张透明的 960×640 空白画布。只读文件夹选择返回空列表时按取消处理。

### 本地文件同步

通过「打开工作目录」获得浏览器的目录读写授权后，素材区的「自动同步本地」默认开启。已提交的绘画、图层、裁切、扩边与缩放等素材改动，在停止编辑约 800ms 后合成可见图层并写回对应图片；新建或复制素材使用不覆盖已有文件的唯一名称。子目录中的原图沿用其文件句柄，工作目录之外的来源文件不会被自动写回，而是在当前目录生成新文件。

界面区分等待、正在写入、已同步、暂停和失败状态；「重试同步」可通过用户操作重新请求目录授权并重试。关闭开关后改用手动保存。只读文件夹导入、未连接目录的工程和浏览器草稿没有文件写入授权，界面会明确提示，后台不会用下载代替同步。

同步使用单文件队列和不可变图片快照。写入过程中产生的新编辑会继续排队，旧快照的完成不会清除新改动；未提交的笔画、文字、曲线或浮动选区会等待完成。手动保存和自动同步相互协调，切换工作区先等待已启动的写入结束，避免将旧任务绑定到新目录。同步仅更新图片文件；可编辑图层、共享参考和各工作模式场景仍通过浏览器草稿及「保存工程」保留。

素材工作区包含多张独立图片。每张图片有自己的图层、活动图层和图像历史；拼接场景、瓦片画布、优化参数和共享参考属于整个工作区。

- **创建素材副本**：每张素材卡片的右上角提供复制按钮，缩略图与紧凑列表视图均可使用，也支持键盘 Enter／空格。点击后自动选中新副本并滚动显示。
- 副本保留画布尺寸、全部图层及其像素、透明度、顺序、名称、锁定、显隐与混合模式；图层像素和编辑历史独立，编辑副本不会影响原素材。尚未确认的文字与浮动选区会先完成提交。
- 新名称自动使用「原名 副本」「原名 副本 2」等，并保留扩展名。副本不继承原文件的保存句柄或路径，仍通过保存／导出操作写入文件；创建时检查工作区数量与图层容量。

参考点、水平线和垂直线可设置名称、精确坐标、颜色、显隐、锁定和吸附；支持点击画布放置，或从绘画标尺拖出参考线。

- **像素坐标**：不同图片使用相同的像素位置，适合同尺寸素材。
- **相对比例**：按基准尺寸的比例映射到当前图片，适合不同尺寸素材。
- **拼接场景**：共享参考以场景原点或内容边界映射显示，随参考定位模式变化。
- **瓦片画布**：左上角固定为 (0,0)，相对参考按指定画布尺寸映射。
- **辅助标记**：参考点、参考线、网格和视口框不写入导出的图片像素。

参考随工作区项目保存，也可单独导出/导入 JSON。在已授权的工作目录中，还可保存 `.paint-guides.json`。

## 区域截图 → 工作区新素材

绘画工具栏与画布左侧工具条新增 **区域截图（K）**，也可从 **图像 → 区域截图 → 新素材** 打开。

- 在画布拖出矩形，拖动框内移动、拖动八个边角手柄调整；X/Y/宽/高使用原图整数像素，支持 1×1 区域、反向拖动及边界限制。方向键移动 1px，Shift+方向键移动 10px；Esc/Delete 只重置截图框。
- 点击实时预览可打开大图。点击 **保存到工作区** 或按 Enter，把可见图层在该区域内的合成结果创建为独立 PNG 素材。截图保留透明及半透明，输出尺寸不受画布缩放影响；网格、参考线、标尺、选框不写入素材。
- 默认留在原图，便于连续提取。名称自动编号避免重名，也可自定义；勾选 **保存后打开** 可直接编辑新素材。保存成功后提供“打开素材”入口，新增素材进入现有草稿、工程保存、拼接与导出流程。
- 截图框与绘画浮动选区独立，调整范围不修改原图。进入工具时完成既有待提交编辑；切换素材或改变原图尺寸后重置截图框。截图工具可读取锁定图层，遵循可见性、不透明度与混合模式。
- 保存到工作区用于创建浏览器中的新素材；保存到磁盘仍使用原有图片导出、保存图片或保存工作区项目。

## 绘画与精修功能

- 铅笔、9 种画笔样式、橡皮、容差填充、取色、前景色/背景色及 HEX/RGB/HSV 颜色编辑。
- 文字、字体与样式、24 种形状、轮廓和填充、多边形与曲线。
- 矩形/自由选区、移动与缩放、剪切、复制、粘贴、透明选择、反选和裁剪。
- 图片/画布尺寸调整、百分比尺寸、保持比例、最近邻或平滑重采样、旋转、翻转、倾斜和反色。
- 图层新增、复制、删除、重命名、排序、合并、显隐、锁定、不透明度和 8 种混合模式。
- 缩放、实际尺寸、适应窗口、平移、标尺、清晰像素显示和可配置间距的网格。
- 当前图层颜色调整及原图、柔和、暖调、黑白预设；锐化保持每个像素的透明度。
- 11×11 像素放大镜、HEX/RGBA/坐标、前景取样；导航器点击/拖动定位；点击历史步骤恢复图片。

精修中的亮度分布是缩略采样预览，不是完整图像的精确像素统计。锐化可能增加颜色数量，与优化模式的限色处理用途不同，应按素材需要选用。

## 文件格式与完整工程

| 用途 | 格式与说明 |
| --- | --- |
| 图片导入 | PNG、JPEG、WebP、BMP、GIF、SVG、AVIF，解码支持取决于浏览器 |
| 绘画图片导出 | PNG、JPEG、WebP、BMP、静态 GIF |
| 拼接图片导出 | PNG、JPEG、WebP；提供范围、倍率、留白和透明背景选项 |
| 瓦片画布导出 | 固定尺寸整图 PNG，或独立 PNG 瓦片 ZIP 与 `layout.json` 坐标清单 |
| 像素转换导出 | PNG、SVG；支持批量转换结果 ZIP，保留透明度 |
| 像素优化导出 | 透明 PNG，支持整数倍率 |
| 批量图片导出 | ZIP，保存工作区中的素材图像 |
| 完整工作区 | `.paintspace` JSON，包含图层像素、图片元数据、混合模式、共享参考、工作区设置、拼接及瓦片源图与场景、切图设置、像素转换、优化及扩边参数 |
| 单独参考 | 参考 JSON 或目录中的 `.paint-guides.json` |

图片格式会合并可见图层；继续分层创作应同时保存 `.paintspace`。完整工程保存已经应用的编辑，不包含尚未确认的精修预览。

### 旧站工程导入

- **旧画境 `.paintspace`**：恢复图片、图层、参考和旧版设置；旧文件没有的新模式数据使用默认状态。
- **旧拼境 `.pinjing`**：恢复源图片和拼接场景。使用统一工程保存后，可与其他模式的数据一并保留。
- **旧 Pixelroom `.pixelroom` 或其 JSON 工程**：保留分层、图层名称、可见性、锁定、不透明度和混合模式。原有位置、缩放、旋转及颜色滤镜会烘焙到每个图层的像素中，原始参数不再单独可编辑。

旧站本机草稿受浏览器站点隔离保护。迁移时应先在原站导出工程或图片，再在统一工作台中导入。重新打开工程会建立新的历史起点：撤销列表保留在当前会话中，不随工程文件持久化。

## 文件夹保存与草稿

支持目录访问的浏览器会在用户选择并授权工作目录后，尝试把编辑结果保存到对应文件。浏览器不支持、没有权限或嵌入环境受限时，使用文件夹导入和下载保存；不保证可以直接写回真实磁盘。

目录读写需要安全上下文、浏览器支持和用户授权。部署后可使用桌面版 Edge 或 Chrome 独立打开站点；恢复项目不会恢复系统目录写入权限，需要重新选择目录。

IndexedDB 自动草稿用于恢复当前浏览器中的工作。清除站点数据、浏览器存储不足或切换浏览器都会影响草稿可用性，因此正式作品应主动保存工程文件和输出图片。

## 快捷操作

- 绘画/精修：`Ctrl/Cmd+S` 保存当前图像；`Ctrl/Cmd+Z` 撤销；`Ctrl/Cmd+Y` 重做；`Ctrl/Cmd+C/X/V` 复制、剪切和粘贴。
- 像素转换/拼接/瓦片/切图/优化/扩边：`Ctrl/Cmd+S` 保存完整工作区工程。
- 切图：拖动横竖切线调整坐标，空格/中键或平移按钮拖动视图，滚轮缩放；`Escape` 取消当前拖动或正在生成的整组切图。
- 瓦片画布：`M` 开启/退出选点测量，`V` 移动素材，`R` 左右拖动素材旋转，`Shift` 旋转按 15° 吸附，`H` 平移，`Alt` 暂停吸附；导出 ZIP 期间按 `Escape` 取消导出。
- 透明扩边：`Ctrl/Cmd+Z` 撤销当前素材的编辑，`Ctrl/Cmd+Y` 或 `Ctrl/Cmd+Shift+Z` 重做。
- 绘画工具：`B` 画笔、`P` 铅笔、`E` 橡皮、`F` 填充、`I` 取色、`T` 文字、`M` 矩形选区、`L` 自由选区、`H` 平移。
- 绘画视图：空格拖动平移，滚轮缩放，`Shift` 约束绘图，`X` 交换前景色与背景色。
- 浮动选区/多边形：`Enter` 完成；`Escape` 取消当前操作。

不同模式使用适合自身的工具和快捷键。完整说明见页面帮助及工具提示。

## 适用范围与限制

- 这是独立实现的网页绘画工具，不是 Microsoft Paint 官方产品，也不宣称与任何 Windows 版本逐项完全一致。
- 没有接入 Microsoft Cocreator、Image Creator 或云端生成式编辑。按颜色去背景使用本地连通区域算法，适合相对纯色背景。
- GIF 导入取静态帧，导出为静态 GIF；没有动画时间轴或系统级“设为桌面壁纸”功能。
- 单张绘画画布每边最多 8192 像素，且总面积受约 3200 万像素限制；模式各自还有导入、图层、输出和累计像素预算。大图、多图层和高倍率导出会增加浏览器内存占用。
- 历史记录受步数和内存预算限制，大图的可回退步骤可能较少。工程重开和草稿恢复保留编辑内容，不恢复此前会话的完整撤销时间线。
- 拼接返回绘画时，场景变换会成为输出图层中的像素；完整工程仍保留可继续摆放的拼接场景。
